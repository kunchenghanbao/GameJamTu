# 萧酉歌｜醉拳家

原创近战角色，玩法参考“醉拳流浪武者”的节奏感：先用普攻和饮酒积累酒势，再用摆步接近、旋壶扫退，最后进入醉意姿态完成爆发。角色不复刻任何现有格斗游戏人物的脸、服装、名称或招式。

## 定位

- 阵营：主角方
- 职业：醉拳家
- 角色编号：8
- 地图头像：91
- 战斗头像：11044
- 主要属性：高攻击、高机动、中等生命，防御偏低
- 核心状态：酒势（43）、醉意（44）、踉跄（45）

## 联动规则

- 酒势每层提高攻击力 6%，最多 3 层。
- 普通攻击会自动叠加酒势，76 技能可以在无法接敌时补充层数。
- 80 的醉意姿态会放大酒势带来的攻击成长，但同时降低防御，鼓励“进攻换生存”。
- 79 的击退与 45 踉跄用于制造下一次近战窗口；敌方单位仍按当前战场阻挡规则处理。
- 玩家方萧酉歌的普攻与主动攻击技能最终伤害 ×1.5；召唤物、持续伤害和其他角色不受影响。
