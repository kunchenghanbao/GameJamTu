# 肉鸽新增技能设计（ID 61–75）

> 状态：`61–75` 共 15 个技能已生成数据并接入肉鸽奖励池；战斗联动按本文规则实现。

## 1. 设计范围

本稿整理 `61–75` 的连续技能编号，其中 `61–66` 为新增剑系技能，`67–75` 为元素、区域和战术技能。

- `61–66`：剑系连携、剑势积累和终结技。
- `67–72`：元素反应、控制和区域技能。
- `73–75`：通用战术、标记和击杀资源技能。
- 现有 `1–60`、敌方技能 `1001–1018` 不改动。
- 新技能只在肉鸽 Run 内生效，等级沿用现有 Lv.1–Lv.3 升级规则。
- 召唤物可以作为持有者的伤害来源，相关击杀统一追溯到根玩家。

## 5. 与现有技能的联动

### 5.1 冰雷超导

- `67 冰晶牢笼` 和现有冰刺术、冰霜新星负责施加冰结。
- 现有放电、雷鸣贯穿、狂雷、轰雷破，以及新增技能中带雷属性的攻击，可以命中冰结目标触发超导。
- 超导仍沿用现有规则：移除冰结、造成范围雷伤害并降低防御；同一次技能释放对同一目标最多触发一次。

### 5.2 燃烧与余烬

- `72 余烬回响` 不主动施加燃烧，负责奖励“先上燃烧、再用其他属性收尾”的打法。
- 烈火印记、火球术、多重火球术、烈焰爆裂等技能可以启动余烬回响。
- 非炎主动直接伤害触发元素爆炸时，先消费余烬回响，再按现有爆炸倍率结算，避免同一段伤害被重复放大。

### 5.3 标记与负面状态

- `74 战术标记` 本身可被 `73 破绽洞察` 视为一个可见负面状态。
- 腐蚀、战术标记、冰结、燃烧、破甲等状态可以共同满足 73 的触发条件；73 的额外伤害不作用于反应追加伤害。
- `70 腐蚀沼域` 只降低防御，不改变敌人的元素免疫和 Boss 软控规则。

### 5.4 剑系推荐循环

1. `67 冰晶牢笼 → 61 霜痕剑 → 放电/雷鸣贯穿`：先用剑系技能吃到冰结增伤并保留冰结，再用雷技能触发超导。
2. `烈火印记 → 62 炽痕剑`：近战剑击作为非炎元素收尾，触发燃烧目标的元素爆炸。
3. `74 战术标记 → 63 破势剑意 → 64 回风剑阵`：标记目标后积累剑势，利用风行结界扩大剑阵范围并获得额外伤害。
4. `70 腐蚀沼域 → 65 终式·裂空`：先削弱防御，再消耗剑势释放终结技；标记和破绽状态可同时提高最终伤害。
5. `66 剑心归一`作为剑系收尾奖励：多目标命中或击杀后回复 SP 并缩短下一轮剑技冷却，鼓励连续进攻而不是单次爆发后停手。

## 6. 击杀归属与肉鸽掉落

这些技能需要和统一的击杀结算配合，避免敌方回合、反击和召唤物走不同路径：

- 归属以最后一次有效伤害来源为准，不以当前是玩家回合还是敌方回合为准。
- 召唤物造成击杀时，沿 `__rogueOwnerIndex` 追溯到根玩家；`72、74、75` 的触发者、经验和肉鸽掉落接收者均为该根玩家。
- 玩家在敌方回合进行反击、追击或其他有效伤害并击杀敌人时，仍生成一组肉鸽掉落。
- 敌方单位造成的、没有玩家归属的击杀不生成肉鸽掉落，也不触发 `75 终结回响`。
- 同一个敌人只允许一次死亡结算，经验、等级、掉落和击杀被动共用 `processedDeathID` 去重。
- 元素反应、持续伤害、屏障吸收和爆炸追加伤害不能单独生成掉落或重复触发 75。

## 9. 验收标准

1. `61–75` 共 15 个技能都能从肉鸽奖励池抽取，并按稀有度和最低层数过滤。
2. 新技能首次获得为 Lv.1，重复选择依次升到 Lv.2、Lv.3，满级后转 100 金币。
3. 61–66 的剑势、冰结/燃烧/风行/腐蚀/标记联动均有明确持续时间和去重规则。
4. Boss 免疫冰结时只获得减速，不会因 67 或元素反应跳过行动。
5. 72 只强化非炎主动直接伤害，元素爆炸追加伤害不重复吃加成。
6. 66、73、74、75 在玩家直接击杀、反击击杀和召唤物击杀时均按归属正确触发。
7. 玩家在敌方回合反击/追击击杀敌人时生成一次肉鸽掉落；没有玩家归属的敌方击杀不生成掉落。
8. 同一敌人的持续伤害、反应追加伤害和爆炸不会重复结算掉落或 66/75。
9. Run 结束、失败、中止或返回主线后，37–42 状态、临时计数和升级效果不会污染主线。

## 10. 推荐实施顺序

1. 先确认 `61–75` 的名称、数值、稀有度和升级效果。
2. 生成技能/状态 JSON，并登记奖励池。

4. 增加召唤物击杀、敌方回合反击击杀和追加伤害去重测试。
5. 接入技能升级表、奖励卡和技能列表显示。
6. 运行构建、肉鸽逻辑测试、技能联动测试和奖励池校验。
