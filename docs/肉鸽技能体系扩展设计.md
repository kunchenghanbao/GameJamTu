# 肉鸽技能扩展设计（简化版，20 技能）

## 1. 设计方向

本次新增技能建议使用 ID `41-60`，只保留三类容易理解、容易在战斗中形成反馈的内容：

| 类别 | 技能数量 | 核心玩法 |
| --- | ---: | --- |
| 血魔流 | 8 | 主动扣血换取伤害、攻击范围和爆发，再通过伤害与击杀吸血，拥有一次锁血容错 |
| 元素反应 | 7 | 冰冻目标受到雷击触发超导；燃烧目标受到其他元素攻击触发爆炸 |
| 状态强化 | 5 | 直接提高攻击、魔力、移动、防御或解除负面状态 |

设计原则：

- 单个技能拿到后立即有效，不要求先凑齐三四张卡才能使用。
- 两张同类技能即可产生明确联动。
- 反应只保留两种，不增加大量元素标记。
- 技能说明写清楚扣血量、吸血量、范围和每回合触发上限。
- 以下数值是首轮测试值，实际实现后根据 9 关 Run 数据调整。

## 2. 血魔流

### 2.1 通用规则

血魔技能的主动扣血属于“生命消耗”，不是受到伤害：

- 不触发反击、受伤事件、伤害减免和敌方击杀判定。
- 按当前生命值比例扣除，因此不会直接把角色扣死，最低保留 1 HP。
- 吸血只计算主动攻击和主动技能造成的直接伤害，不计算持续伤害、元素反应伤害和反伤。
- 单次行动的总吸血量最多为角色最大生命值的 25%，避免范围技能一次回满。
- “致命伤害保留 1 HP”每场战斗只能触发一次。

新增状态：

| 建议状态 ID | 状态 | 效果 |
| ---: | --- | --- |
| 27 | 血怒 | 最多 5 层，每层攻击和魔力 +6%，持续至战斗结束 |
| 28 | 血域 | 主动攻击和主动技能的最大释放距离、作用半径各 +1，持续 2 回合 |
| 29 | 不灭血印 | 表示本场战斗的锁血效果尚未触发；触发后移除 |

攻击范围增加规则：

- 单体、直线和可指定区域技能的最大释放距离 +1。
- 范围技能的作用半径 +1。
- 近战普通攻击仍保持近战，不受血域影响。
- 全体技能、被动技能、召唤技能不受血域影响。

### 2.3 血魔流战斗循环

基础组合：

1. 使用血刃或血爆环主动压低生命并积累血怒。
2. 生命低于 50% 后，沸血扩张增加技能范围。
3. 饮血通过直接伤害和击杀把生命拉回安全线。
4. 血契不灭提供一次失误容错。
5. 血怒达到较高层数后使用血海葬阵完成大范围爆发。

这套体系的风险来自低生命值，而不是随机失败。玩家可以选择继续压血提高输出，也可以先击杀小怪吸血。

## 3. 元素反应

### 3.1 只保留两种反应

#### 超导

触发条件：带有现有“冰结”状态的目标受到雷属性主动伤害。

效果：

- 移除冰结。
- 目标周围 1 格内的所有敌人受到施法者 `MAG 60% + 15` 的雷属性伤害。
- 被超导命中的敌人物防和魔防下降 20%，持续 2 回合。
- Boss 的冰结本来就应转换为减速状态；雷击该减速状态时同样可以触发超导。

#### 元素爆炸

触发条件：带有现有“燃烧”状态的目标受到冰、雷、水、土、风、光或暗属性主动伤害。

效果：

- 移除燃烧。
- 目标周围 1 格内的所有敌人受到本次主伤害 50% 的炎属性爆炸伤害。
- 爆炸不会再次触发超导、元素爆炸、暴击、吸血或技能命中效果。

共同限制：

- 同一目标在一次技能释放中最多触发一次元素反应。
- 多段技能也只在第一次满足条件的命中时触发。
- 反应伤害来源记录为原施法者，保证击杀和肉鸽奖励归属正确。
- 两种反应在肉鸽模式启用，暂时不改变主线战斗。

### 3.3 与现有技能的联动

不要求玩家只能使用新技能：

- 现有冰刺术、冰霜新星能够提供冰结，之后使用放电、雷鸣贯穿、狂雷或轰雷破都可触发超导。
- 现有火球术、多重火球术、烈焰爆裂和终极爆弹能够提供燃烧，之后使用任意非炎元素攻击都可触发元素爆炸。
- 现有技能只有在肉鸽模式中才获得上述反应能力。

## 5. 肉鸽奖励池

不做复杂的体系解锁，只使用简单权重：

- 41、42、43、49、50、52、53、56、57、58 为普通技能，可直接出现。
- 44、45、46、51、54、59 为稀有技能。
- 47、48、55、60 为传说技能，从第 4 关开始出现。
- 玩家持有任意血魔技能后，其他血魔技能出现权重提高 50%。
- 玩家持有冰技能后，雷技能出现权重提高 30%；持有雷技能后，冰技能出现权重提高 30%。
- 玩家持有炎技能后，元素引爆和非炎元素技能出现权重提高 30%。
- 一次三选一最多出现两张同类技能，保留其他构筑方向。
- 被动技能不能重复获得，重复时转换成金币或恢复奖励。

## 6. 实现边界

建议新增一个集中处理器 `RogueSkillSynergySystem.ts`，不要把联动拆散写进每个技能事件。

处理器负责：

- 血魔技能的生命消耗、血怒层数、吸血上限和一次锁血。
- 血域对释放距离和作用范围的临时修改。
- 检测冰结 + 雷、燃烧 + 非炎元素两种反应。
- 给反应伤害添加“不可再次触发联动”的标记。
- 记录每次技能释放已经触发过反应的目标。
- 战斗结束时清理锁血次数、吸血累计、血怒和血域。
- 仅在 `RogueRunManager.active` 时启用，防止影响主线。

其中强攻、魔力集中、迅捷、铁壁、极限解放可以主要依靠现有状态配置完成；元素反应、血域改范围、主动扣血、伤害吸血和锁血需要代码支持。

## 7. 验收标准

1. 技能 ID 41-60 共 20 个技能均可从肉鸽奖励中获得。
2. 主动扣血最低保留 1 HP，不触发反击或受伤事件。
3. 饮血只吸取主动直接伤害，单次行动回复不超过最大 HP 的 25%。
4. 血契不灭每场只触发一次，触发后角色保持 1 HP 且不会继续结算该次攻击的追加伤害。
5. 血域只扩大允许扩大的技能，不改变近战普通攻击、全体和召唤技能。
6. 雷伤害命中冰结目标稳定触发超导并移除冰结。
7. 非炎元素命中燃烧目标稳定触发元素爆炸并移除燃烧。
8. 反应伤害不会再次触发反应、吸血、暴击或技能命中效果。
9. Boss 不会被连续冰结跳过行动，但仍能受到超导伤害和防御下降。
10. 肉鸽结束、失败或中止后，所有新增技能和临时状态都不会污染主线。
